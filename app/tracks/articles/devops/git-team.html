Git تیمی بدون ترس: برنچ، ری‌بیس و پیام کامیت

آ آرش پناهی ۱۸ مهر ۱۴۰۵ ۷ دقیقه مطالعه

ترس از Git معمولاً از یک تجربهٔ بد می‌آید: یک merge conflict حل‌نشده یا یک push اشتباه. راه‌حل، حفظ کردن صد دستور نیست؛ داشتن یک گردش کار پیش‌فرض و دانستن سه ابزار نجات است.

گردش کار روزانه

git switch -c feat/better-tea   # برنچ کوچک و کوتاه‌عمر
# ... تغییرات ...
git add -p                    # مرور تکه‌تکهٔ تغییرات
git commit -m "feat: افزودن دم‌کردن دوم"
git pull --rebase origin main   # تاریخ خطی
git push -u origin feat/better-tea

پیام کامیت، نامه به آینده

  • خط اول کوتاه و امری: «feat: …»، «fix: …»، «refactor: …».
  • بدنه توضیح دهد «چرا»، نه «چه»؛ چه را diff می‌گوید.
  • کامیت‌های کوچک و قابل بازگشت؛ هر کامیت یک تصمیم.
نکتهٔ منتور: سه ابزار نجات: git reflog (تاریخچهٔ اشاره‌گرها)، git stash (کنار گذاشتن موقت) و git switch --detach (بازدید بدون تغییر). با این‌ها تقریباً هیچ چیزی برای همیشه گم نمی‌شود.
